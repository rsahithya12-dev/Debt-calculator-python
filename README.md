# Debt Calculator Using Python

## 📌 Project Description
The Debt Calculator is a simple Python-based application designed to calculate Simple Interest, Compound Interest, and Equated Monthly Instalments (EMI).

This project helps users perform basic financial calculations quickly and easily using a menu-driven program.

## ✨ Features
- Simple Interest Calculation
- Compound Interest Calculation
- Monthly EMI Calculation
- Total Amount Calculation
- Total Interest Calculation
- User-friendly menu-driven interface

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code / Python IDLE

## 🧮 Calculations Used

### 1. Simple Interest
Simple Interest = (Principal × Rate × Time) / 100

### 2. Compound Interest
Compound Interest = Principal × (1 + Rate/100)^Time - Principal

### 3. EMI
The EMI is calculated using the standard loan repayment formula.

## ▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the Python file using:

```bash
python debt_calculator.py
```
